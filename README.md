# Divine Touch Barbering Saloon

Welcome to the official repository for the Divine Touch Barbering Saloon website. 

## About
Divine Touch is a premium barbershop located in Accra, Ghana, dedicated to providing top-tier grooming and an elite experience for our clients. 

## Features of this Website
*   **Custom Hero Section:** A high-quality visual representation of our brand using our official flyer.
*   **Hairstyle Gallery:** A responsive, animated gallery showcasing 9 of our best precision cuts and styles.
*   **Contact & Hours:** Clear, click-to-call phone numbers and easily readable opening hours so clients can book instantly.

## Tech Stack
*   HTML5
*   CSS3 (Grid & Flexbox for responsiveness)
*   JavaScript (Lightbox gallery functionality)
